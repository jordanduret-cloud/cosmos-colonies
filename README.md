# Cosmos Colonies

Jeu de gestion spatial pour téléphone, en cours de développement.

- `index.html` : tout le jeu (interface, logique, sauvegarde locale dans le navigateur).
- `art/` : illustrations (personnages, bâtiments, ressources, packs, vaisseau).
- `models/` : modèles 3D convertis, avec leurs textures.
- `manifest.json` et `icon-*.png` : installation comme application sur l'écran d'accueil.

Le jeu se lance en ouvrant `index.html` depuis un serveur web (GitHub Pages par exemple). Three.js et les polices sont chargés depuis un CDN.
